# External Portals, Social Media Entities & Anti-Hallucination Rule

When integrating external portals, social media channels, community hubs, or third-party links across Nugget Nihongo:

1. **Grounded Entity Status (Zero Hallucination / Zero Pre-Emptive Assumption)**:
   - Strictly NEVER assume, invent, or pre-emptively generate live links for channels that the user has not yet created (e.g. Discord servers, Telegram channels, Instagram accounts).
   - Only attach active hyperlinks to URLs that the user has explicitly verified and confirmed as live and registered.
   - If a channel is planned but not yet created by the user, clearly designate it as `Segera Hadir` (Coming Soon) or `Tahap Persiapan` with a disabled/inactive state, avoiding broken links or phantom invitations.

2. **Accurate Linguistic Framing (No Internal Community Illusions)**:
   - Nugget Nihongo utilizes an **External Community Hub** model connecting to external social media and creator platforms, not an internal in-app forum.
   - Never label algorithmic or curriculum features as "Community" when they are system-generated (e.g., use **"Tantangan Kanji Harian"** / **"Kanji Hari Ini"**, NEVER "Daily Community Kanji").
   - Explicitly frame sharing actions as broadcasting to external platforms (e.g., "Bagikan ke Media Sosial", "Bagikan ke 𝕏 dengan #NuggetNihongo").

3. **Creator Support & Micro-Donation Prominence**:
   - For verified creator channels such as Trakteer (`https://trakteer.id/nugget-nihongo`), present them transparently as optional support for server infrastructure, free educational access, and maintenance, using authentic Indonesian vernacular ("Traktir Kopi Sensei").
