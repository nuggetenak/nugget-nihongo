# Nugget Nihongo (Next.js Overhaul)

A complete 100% total frontend overhaul of **Nugget Nihongo** — modern gamified Japanese learning application for Indonesian speakers.

## 🚀 Key Features

*   **⚡ Next.js 15 App Router & Turbopack:** Blazing-fast routing and modern architecture replacing legacy Vanilla JS strings.
*   **🎨 Glassmorphism & Minimalist UI:** Built with Tailwind CSS v4, dark-mode native feel, custom warm amber/gold gamification tokens.
*   **🌱 Kebun Mastery & Gamification:** Real-time streak tracking, XP leveling, and daily quest reward claims.
*   **🧠 FSRS-4D Spaced Repetition Engine:** Scientifically grounded memory scheduler (Ye et al., 2022) with 4-button rating feedback (Lagi, Sulit, Bagus, Mudah).
*   **🤖 AI Sensei (Google Gemini API):** Integrated bilingual conversational tutor with native Japanese persona, sentence correction, and audio speech pronunciation.
*   **📚 Complete JLPT N5 - N1 Database:** Over 4,800+ vocabulary items and 850+ grammar rules with nuance notes, examples, and audio.
*   **🔍 Instant Global Search:** Real-time search (`Ctrl+K` / `Cmd+K`) across words, readings, and grammar patterns.
*   **💾 Local Storage & Export/Import:** Automatic offline progress persistence with JSON export and import capabilities.

## 🛠️ Development

```bash
# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
